# Immersive review brief and rubric

## Brief

Create a Finnomena Exclusive, full-bleed landing page. Use editorial asymmetry, purposeful media, one in-page CTA, source-supported proof, and a labeled multi-asset educational visual; never render workspace chrome or a form.

## Rubric

- The page reads as full-bleed landing content, not a workspace.
- Hero hierarchy, editorial asymmetry, and media crop are purposeful; copy and controls remain unobscured.
- Finnomena Exclusive colorway uses yellow as a tier field/highlight with navy text.
- Multi-asset colors encode only labeled category/value data and do not leak into decorative page fields.
